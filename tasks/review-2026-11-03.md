# 925law website review (2026-11-03)

Scope: `website/` (shipped site) and `bearbeiten/` (source + generator). Four independent read-only reviews: code quality, responsive/mobile, design, security/privacy. Key claims were re-verified by hand (grep of source, PHP and image bytes; screenshot of the 375px fold).

Line numbers refer to `website/index.html` unless stated; `en/index.html` has a byte-identical stylesheet.

---

## Executive summary

- **Responsive: yes, genuinely.** Measured from the DOM with real Chrome at 320/375/390/768/1024/1440/1920: no horizontal overflow, rem-based type, clamp() headline, minmax grid, 16px inputs, no-JS mobile nav. Weak spots: hero pushes the CTA below the fold on phones, a dead zone at 861–1000px, tap targets of 18–20px, headline overflows at 200% user font size.
- **Design: 6/10.** Confident typography and a single accent colour, but the trust architecture is wrong for a solo practice: no name, title, city or face above the fold; "Über mich" is the last section; no phone/address on the main page; the "Warum" section is four unproven adjectives; form fields are a 1.32:1 hairline; OG image and favicon use fallback fonts.
- **Security: two High issues, both confirmed.** (1) The auto-reply echoes the attacker-chosen message to an attacker-chosen address from kontakt@925law.de with no length cap, rate limit or server-side consent check: a backscatter spam/phishing relay. (2) No `.htaccess`: no forced HTTPS, HSTS or security headers.
- **Code: one High issue that spans all areas.** The shipped generator `build_site.py` is stale. The source `925law.html` still loads Google Fonts; the script never removes them, never adds `/fonts.css` or Plausible, and uses sandbox paths. Following the handover instructions ("edit, then run build_site.py") silently ships Google Fonts, contradicting the privacy policy, and drops analytics.
- **Also confirmed:** every image (portrait, OG images, favicons, SVG) carries C2PA provenance metadata naming "Anthropic / Claude provided this file". Strip before launch.

## Priority list before launch

### Critical / High
1. **Stale generator reintroduces Google Fonts** — `bearbeiten/925law.html:8-10` has `fonts.googleapis.com` links; `bearbeiten/build_site.py` has no code for fonts.css/Plausible removal or insertion (grep: no match); paths `:7-8,212-214` point to `/mnt/user-data/outputs`. Fix: replace the Google links in the source with `<link rel="stylesheet" href="/fonts.css">` plus the Plausible tag, make paths relative to `__file__`, add `assert "googleapis" not in out` after build. Also generator does not set `input[name=lang]`, translate the portrait `alt`, or pick `og-image-en.png` for EN.
2. **Auto-reply spam relay** — `kontakt.php:41-43` no length limits; `:85,:92` echo `$message`; `:138,:163` sent as `From: 925law <kontakt@925law.de>`. Exploit: one curl POST sends a DKIM-aligned mail with arbitrary text to any address. Fix: stop echoing the message (neutral confirmation only), cap name 100 / email 254 / message 5000, check `consent` server-side, add a time-token or per-IP limiter.
3. **No `.htaccess`** — add: force HTTPS + canonical host, `Options -Indexes`, deny `bearbeiten/`, `.py`, `.txt` (except robots.txt), HSTS, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, CSP (start Report-Only; hashes for the four inline scripts; `connect-src https://plausible.io`), `display_errors Off`. Full block is in the security reviewer's report (reproduced in section 4 below).
4. **C2PA metadata in all images** — `portrait.webp`, `og-image*.png`, `apple-touch-icon.png`, `favicon-32.png`, and a multi-KB `<metadata><c2pa:manifest>` block in `favicon.svg`. Fix: `exiftool -all= -overwrite_original` / `magick -strip` / re-encode; delete the SVG `<metadata>` element and `xmlns:c2pa`.
5. **No-JS form path** — `kontakt.php:23,28` redirect to `index.html?sent=1` / `?error=1`; EN users land on the DE page; `?error=1` is handled nowhere; `Content-Type: application/json` (`:14`) sent even on redirects. Fix: `$back = $lang==='en' ? '/en/' : '/'`, 303 redirect, handle `?error=1` in the page.

### Medium
6. **Consent only client-side** — `index.html:898` `required`; `kontakt.php` never reads `$_POST['consent']`. Also the checkbox wording is consent but `datenschutz.html:54` cites Art. 6(1)(b)/(f): pick one (lawyer).
7. **Auto-reply HTML imports Google Fonts** — `kontakt.php:122` `@import url('https://fonts.googleapis.com/...')`. Delete the line.
8. **Honeypot drops real messages silently** — `kontakt.php:37-39` returns success on a filled `website` field; password managers autofill fields named `website`. Rename the field and tag instead of drop.
9. **Plausible is live on all four pages before a DPA exists** — `index.html:711`, `impressum.html:10`, `datenschutz.html:10`. `DEPLOY.txt:40` claims no tracking; `UEBERGABE.txt` is right. Sign the DPA or remove the tags plus policy section 5.
10. **Privacy policy gaps** — auto-reply e-mail not mentioned (`datenschutz.html:53`), no note on unencrypted mail transport (relevant under §43a BRAO), log retention vague, mailbox host unknown. EN visitors consent to a German-only policy (`en/index.html:898`).
11. **Impressum** — `impressum.html:50` still links the EU ODR platform, discontinued 20 July 2025; remove. brak.de link should point to the Berufsrecht page. Insurance scope "Deutschland" to verify. (Lawyer items.)
12. **Legal pages German-only, back link always `/`** — generate `en/impressum.html`, `en/datenschutz.html` from one template; make the back link language-aware.
13. **CSS duplicated 4×** — ~700 lines inline in both index files, partial copies in legal pages that already drifted (`h1 margin-bottom` 32 vs 12px, `h2` 1.05 vs 1.1rem). Extract `/site.css`.
14. **I18N drift** — 13 keys where source markup text differs from the dictionary (e.g. `925law.html:751` "Persönlichkeiten — ohne Umwege." vs dict "Persönlichkeiten. Ohne Umwege."; `:762` "Unternehmen" vs "Unternehmer"); 5 unused keys; regex at `build_site.py:14` breaks on any `});` in a value. Move the dictionary to `i18n.json`, fail the build on missing keys.
15. **Untranslated strings on EN** — `en/index.html:787` `aria-label="Erklärung zu 925"`, `:884` honeypot label "Bitte leer lassen".
16. **JSON-LD** — `build_site.py:44` uses the EN description for DE; `inLanguage` is not valid on `Attorney`; street address missing although present in the Impressum.
17. **Form UX** — `index.html:966` uses `alert()`; no `aria-live`; no double-submit guard.
18. **Landmarks** — footer content lives inside `<section id="about">` (`925law.html:885-900`); CSS/JS target a `footer` element that does not exist; no skip link; legal pages have no `<main>`.

### Responsive (all Medium/Low; nothing broken)
19. **CTA below the fold on phones** — `#hero { min-height:100vh; justify-content:center }` (`:181`) after a 187–270px static nav. At 390×740 the button lands at y≈760. On 768 the inverse: ~350px blank above and ~400px below. Fix: in the mobile query `#hero { min-height:auto; padding:48px 0 64px }`; use `100svh` elsewhere (`:41,:52,:181`).
20. **Dead zone 861–1000px** — single breakpoint at 860 (`:660`); at 861 the content column is 477px and the About text column 201px next to a 220px portrait. Raise breakpoint to ~1000 or make `main` padding `clamp(24px,5vw,72px)` and stack `.about-grid` below 1000.
21. **Tap targets** — nav links 20px tall, DE/EN 18×18 (`:96-102,:133-157`). Add padding to reach 44px.
22. **Headline overflows at 200% font** — `clamp(2.4rem,5.2vw,4rem)` (`:227`) lower bound is rem-only; at 375px/200% scrollWidth becomes 422. Use `clamp(min(2.4rem,11vw),5.2vw,4rem)`; size the stamp in rem not px.
23. **Body copy 13–15px on mobile** — service text .94rem, labels .88rem, consent .82rem, footer .85rem. Bump in the mobile query.
24. **Scroll snap on a 6000px page** — `html { scroll-snap-type:y proximity }` (`:26`). Remove.
25. **Sidebar `height:100vh`** cannot scroll at large font on short windows; use `min-height` + `overflow-y:auto`.
26. **Portrait** — no `width/height` attributes, no `loading="lazy"`, 640×946 for a 220×280 box.
27. **No `prefers-color-scheme`** handling (conscious choice, fine). `prefers-reduced-motion` is handled well.

### Design
28. **Lawyer invisible above the fold** — no name, "Rechtsanwalt", Berlin or face in the first viewport; About is the last section (~5400px down). The `.kicker` style (`:218`) exists with no element: use it for "Max Englhard · Rechtsanwalt · Berlin · DE/EN"; move `#about` after `#services`; consider a small portrait in the hero.
29. **No phone/address/response-time on the main page.** Add to sidebar bottom and beside the form; "Antwort innerhalb eines Werktags".
30. **"Warum 925law" is four adjectives** (Direkt / Erstklassig / Klar / Passgenau). Replace with proof: Großkanzlei background, both sides seen, 190 € fixed-fee first consultation fully credited, DE/EN.
31. **Form fields nearly invisible** — border `#DEDAD4` on `#FAF9F7` = 1.32:1 (`:558`); WCAG needs 3:1. Use `#B9B4AC` or a full border with light fill.
32. **Pacing** — all grids are `1fr` (`:451,:478,:503`) so Why/Steps are stacked one-liners with ~260px dead space right. Make Why 2×2, Steps 4-col/2×2, Situations 2-col ≥1100px.
33. **OG images** rendered in Arial with a serif URL; EN headline orphans "law.". Regenerate with the real woff2.
34. **Favicon** illegible at 16/32px, Arial text; four inconsistent brand marks. One mark system: small variant without inner ring, "925" as paths.
35. **Copy** — "für Persönlichkeiten" reads as "for celebrities"; use "für Unternehmen, Führungskräfte und Freelancer". Sub-line orphans at 1440: `text-wrap:balance`. The 925* explanation is 5000px away: add a one-liner under the stamp.
36. **Contrast table** — ink 17.2:1, ink-soft 8.44:1, accent on bg 4.89:1 (AA only; avoid below 14px, `.fn-num` at `:626` is borderline), white on accent 5.14:1, lang-switch "/" 1.32:1 (make it aria-hidden/ink-soft). `--accent-soft` unused.
37. **Type scale** has 12 ad-hoc sizes between 13 and 17px; collapse to 4 tokens.
38. **Legal pages** lack brand mark and footer; 720px vs 960px measure.

### Low / housekeeping
- Dead CSS ~15%: `.kicker`, `.slogan-strip`, `.legal-section/.legal-grid`, `select` rules, `.tall`, `about-main`, duplicate `#hero` and reduced-motion blocks, `--serif` naming a sans.
- BeautifulSoup output (`<meta charset="utf-8"/>`, `required=""`) trips html-validate (76 errors, cosmetic); use `formatter="html5"`.
- `fonts.css:7` IBM Plex Sans 500 is never used; drop the file. No font preload. Add `OFL.txt` to `fonts/` (licence requires it).
- `fetch_fonts.py` downloads with no checksum; record sha256 of the shipped woff2 and verify.
- `DEPLOY.txt` ships inside the webroot and is wrong on three points (fonts empty, auto-reply DE-only, no tracking). Delete or move out.
- Meta descriptions ~235 chars; trim to ~155.
- No caching headers for immutable assets; add `Cache-Control: immutable` for `/fonts/`, images.
- `@mail()` suppresses failures; add `Content-Transfer-Encoding: 8bit`, `wordwrap(…,990)`, `error_log` on failure.
- SPF/DKIM/DMARC for 925law.de must authorise Hetzner's outbound; verify after deploy with a mail-tester.

## What is already good
- Correct viewport meta, no `user-scalable=no`, no horizontal overflow at any width, sticky (not fixed) sidebar, no-JS nav and form, `focus-visible` outlines, `prefers-reduced-motion`.
- Heading hierarchy, alt text, labelled fields, `rel="noopener"`, canonical + hreflang (head and sitemap), `noindex` on legal pages, real-link language switch.
- Self-hosted fonts with `font-display:swap` on the live pages; no cookies, no third-party embeds other than Plausible.
- `kontakt.php`: method check, honeypot, `FILTER_VALIDATE_EMAIL`, CRLF stripping, `lang` whitelist, fixed redirect targets, constant `-f`, From = own domain with visitor in Reply-To, output encoding in HTML reply, random MIME boundaries, `Auto-Submitted`, RFC 2047 subjects, no reflected input.
- Archivo 900 + IBM Plex Sans pairing, single magenta accent, accent bar before h2, the "Wenn es ernst wird" scenarios, the fixed-fee first consultation with full crediting.
